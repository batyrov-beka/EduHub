# EduHub — студенттер үчүн вакансиялар платформасы

Дипломдук долбоор: «Django фреймворку менен студенттердин маалымат базасын автоматташтыруучу вакансиялык веб-сайтты иштеп чыгуу».

## Мүмкүнчүлүктөр

| Роль | Эмне кыла алат |
|---|---|
| **Студент** | Катталуу (email + OTP код), резюме түзүү, вакансияларды издөө жана чыпкалоо, арыз берүү (коштомо кат менен), арыздын статусун көрүү, арызды кайтарып алуу, көндүмдөр боюнча сунушталган вакансиялар, билдирүүлөр |
| **Иш берүүчү** | Катталуу (ИНН/компания), админдин текшерүүсүн күтүү, вакансия жарыялоо/түзөтүү/жабуу/өчүрүү, арыздарды кароо, кабыл алуу же четке кагуу (студентке билдирүү + email кетет) |
| **Администратор** | Статистика (диаграммалар), иш берүүчүлөрдү ырастоо, колдонуучуларды бөгөттөө/өчүрүү, вакансияларды өчүрүү, билдирүү таратуу, Excel (CSV) отчеттор |
| **Баары** | Материалдар (макалалар), форум (суроо-жооп, лайк, эң жакшы жооп), эки тил (кыргызча/орусча) |

## Технологиялар

Python 3.13, Django 6.0, SQLite, HTML/CSS/JavaScript (AJAX), Bootstrap Icons, Gmail SMTP, Telegram Bot API.

## Структура

```
eduhub/      — жөндөөлөр (settings.py), URL'дер, тесттер (tests.py)
users/       — колдонуучу модели, каттоо, кирүү, OTP, сырсөздү калыбына келтирүү
jobs/        — вакансиялар (модель, издөө/чыпкалоо, иш берүүчүнүн кабинети)
forms/       — резюме жана арыздар (Application)
Dashboard/   — админ панели, статистика, отчеттор, билдирүүлөр
materials/   — макалалар
forum/       — форум
templates/   — HTML шаблондор
static/      — CSS дизайн-система, сүрөттөр
locale/      — котормолор (ky, ru)
```

## Ишке киргизүү (Windows)

```bash
cd Desktop\EduHub
env\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo          # демо маалыматтар (милдеттүү эмес)
python manage.py runserver
```

Браузерде: http://127.0.0.1:8000

* `python manage.py seed_demo --reset` — эски сыноо вакансияларын өчүрүп, таза демо маалыматтарды толтурат.
* Демо аккаунттардын сырсөзү: `demo12345` (студенттер: `aibek`, `aizada`, `nurlan`, `meerim`, `bektur`; иш берүүчүлөр: `osh_soft`, `alai_market`, `nur_design`, `bilim_center`).
* Админ түзүү: `python manage.py createsuperuser`

## Тесттер

```bash
python manage.py test eduhub
```

22 тест: каттоо жана OTP, кирүү, бөгөттөө, вакансиялардын чыпкалары, ролдор боюнча укуктар, арыз берүү, статус өзгөртүү, резюменин купуялуулугу, админ панели, CSV отчеттор, бардык барактардын ачылышы.

## `.env` файлы

`.env.example` файлын `.env` деп көчүрүп толтуруңуз. `EMAIL_PASS` бош болсо, каттар (OTP коддор) терминалга чыгат — локалдык текшерүү үчүн ыңгайлуу.
